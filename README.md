## 🌌 The Intelligence Core

J.A.R.V.I.S. (Just A Rather Very Intelligent System) is not just a chatbot. It is a **Stateful Agentic System** designed to bridge the gap between AI reasoning and physical browser execution. 

Leveraging the **Multimodal Live API**, J.A.R.V.I.S. combines sub-second voice latency with high-fidelity vision and real-time internet search grounding.

## 🏗️ The Multi-Layered Architecture

### 1. The Commander (Frontend)
- **Engine:** `gemini-3.1-flash-live`
- **Role:** Handles real-time voice, vision, and system-level instruction.
- **HUD:** Built with React/TS and Motion for a cinematic experience.

### 2. The Execution Agent (Python Backend)
- **Engine:** `FastAPI` + `Playwright` / `Selenium`
- **Role:** High-precision DOM interaction and media automation.
- **Intelligence:** Uses specialized locators and `jarvis_id` injections for perfect reliability.

## 🛠️ Installation

```bash
# 1. Clone the suit
git clone https://github.com/Susant07-star/Jarvis-AI.git

# 2. Power up the Brain
cd Jarvis-AI
npm install
npm run dev

# 3. Connect the Hands
cd server
pip install -r requirements.txt
python server.ts
```
